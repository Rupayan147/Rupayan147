## ⚡ CURRENTLY BUILDING

<div align="center">
  <h3><a href="https://github.com/Rupayan147/Unione-APP">UNIONE — AI-Assisted Government Benefits Discovery Platform</a></h3>
  <p><b>Mobile-first AI interface simplifying complex public support programs into a guided journey.</b></p>
</div>

```txt
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  DISCOVER    │ ──> │  UNDERSTAND  │ ──> │    APPLY     │ ──> │    TRACK     │
│ Benefit Feed │     │ Eligibility  │     │ Document List│     │ Case Status  │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

- **Features:** Personalized command center, *Ask Unione* conversational Q&A flow, benefit detail breakdown, application tracking, local state persistence (`AsyncStorage`).
- **Stack:** `React Native` · `Expo Router` · `TypeScript` · `Tailwind CSS (NativeWind)`
- **Scope & Roadmap:** Current repository is a functional mobile prototype with local demo state. Production evolution roadmap includes RAG knowledge retrieval, vector embeddings, official government API ingestion, and secure auth.
- **Repository:** [`github.com/Rupayan147/Unione-APP ↗`](https://github.com/Rupayan147/Unione-APP)
